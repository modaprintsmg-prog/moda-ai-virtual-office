MODA PRINT AI VIRTUAL OFFICE — prototype

Cara mencoba:
1. Buka index.html melalui hosting web statis yang mendukung HTTPS.
2. Koneksi internet diperlukan untuk memuat Three.js dari jsDelivr CDN.
3. Geser untuk memutar kamera, cubit untuk zoom, ketuk avatar/ruangan untuk memilih.
4. Tombol Masuk ruangan mengarahkan kamera ke ruangan terpilih.

Catatan:
- Ini prototipe visual 3D, belum terhubung ke Make.com atau AI sungguhan.
- Avatar dibuat dari bentuk 3D sederhana, bukan model manusia realistis.
- Tidak ada API berbayar yang digunakan.
